# 早读分贝测试器

实时检测学生朗读声音分贝、带弹跳小数动画、可设置早读时长与理想音量线。

## ⚠️ 为什么不能直接双击 index.html？

浏览器出于安全，**`file://` 协议下禁止使用麦克风**。必须在 `localhost` 或 `https` 下打开。
所以请用下面的「一键启动器」，它会自动用本地服务器(`localhost`)打开页面。

## 使用方法（任选其一）

### 方式一：一键启动器（推荐，最简单）
1. 把本文件夹整体下载 / 拷贝到你的电脑
2. **Windows**：双击 `start.bat`
3. **macOS / Linux**：终端运行 `bash start.sh`（或赋予权限后双击）
4. 浏览器自动打开 `http://localhost:8080`，点「允许」麦克风即可

> 需要电脑已安装 Python（Windows 10/11 可在 Microsoft Store 安装 Python；Mac 自带）。

### 方式二：手动开服务器
在文件夹内打开终端，运行：
```
python -m http.server 8080        # Windows
python3 -m http.server 8080       # macOS / Linux
```
然后浏览器访问 `http://localhost:8080`。

### 方式三：部署到 HTTPS（手机也能用）
上传到 GitHub Pages / Vercel 等任意 HTTPS 空间，用手机或电脑打开链接即可
（HTTPS 下麦克风默认可用，无需服务器、无需安装任何东西）。

## 功能
- 打开即自动请求麦克风权限（被拦截时点一下页面即可授权）
- 大号分贝数字 + 弹跳小数动画
- 音量进度条 + 理想音量标线（可拖动滑块设置 40–100 dB）
- 早读倒计时（1–120 分钟），结束自动响铃
- 顶部诊断行显示当前环境是否支持麦克风，便于排查问题
